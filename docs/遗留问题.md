## 2. 需要补齐的运行证据

| 范围 | 当前边界 | 启动与关闭条件 |
|---|---|---|
| 窗口并发 | 多连接共享窗口、两个窗口同时输入未取得完整最终打包组合证据 | 改相应接线或出现竞争故障时，按 [并发回归矩阵](并发网页操作.md#8-回归矩阵) 记录实际输入和票据 |
| 故障竞争 | 真正断连重连、持续 wheel 无回包、弹窗确认期间 opener 关闭或租约换代未完整实测 | 验证旧操作终态、blocked 恢复依据与页面副作用；不能用重连或本地 promise 拒绝代替已终止证据 |
| 人工接管 | 验证码、多因素登录、完整输入法 composition 与触摸未覆盖 | 具体需求或故障触发后补验；已派发 Chromium 输入无法保证撤销 |
| 外部 Chrome | 不具备 Electron 宿主的窗口级输入隔离 | 维护既有回退行为；扩展保护前先定义真实窗口权威与投递边界 |
| 交互诊断 | 空点、探测失败、错误码呈现及运行中面板追加需按具体问题复现 | 先固定失败样本，再按 [网页交互](网页交互.md) 验证原始回执与真实页面效果 |
| 模型行为与成本 | 有真实恢复样本，受控 A/B 尚不足以确认稳定费用或整体成功率改善 | 按 [测量口径](上下文膨胀-测量口径.md) 固定条件并保存原始请求；模型偏差单列 |
| 多实例网页能力 | 2026-10-17 首轮实跑：A/B 同开时 B 侧拿不到 `webpage_*` 工具，A 退出后 B 即可使用 —— 疑似同一时刻只允许一个实例持有；反向（B 持有时 A 取不到）未复验，A 重启后模型请求重试 5/5 失败 | 先定位争用的到底是什么（宿主侧能力服务只允许一个客户端？provider 抢了本机固定资源？），再确认能否参数化；在此之前不宣称实例间网页能力可并行，见 [本地多实例测试方案](本地多实例测试方案.md) §6.4 |
| 实例 workspace 权限 | 装配出的实例 workspace 继承到的 ACL 挡住 shell 工具，模型会转去申请 `danger-full-access` 跑权限修复脚本（本轮已拒绝，未执行） | 在装配脚本里对新实例 workspace 补显式 ACE（`icacls … /grant "<域>\<用户>:(OI)(CI)(F)"`），或明确把实例 workspace 落到已有该 ACE 的位置 |

Chrome live、元素截图裁剪、便携数据隔离和当前开发入口修复已验证，其历史结果保留于验收记录；后续改动仍需对应回归。上游 mandatory-status handler 的开发态提示不构成官方更新政策接口验收通过。
