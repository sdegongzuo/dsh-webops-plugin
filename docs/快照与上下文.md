# 快照与上下文

本说明定义当前工具描述、参数校验、快照读取与输出预算。动作及旧引用恢复见 [网页交互](网页交互.md)，标签调用权见 [页面归属与接管](页面归属与接管.md)。

## 1. 能力范围

当前注册 16 项网页工具（15 项专用接口 + `webpage_tools` 加载入口），保持专用接口。完整快照、区域读取、find 缓存、等待附观察及动作后可选观察共同控制读取成本。

逐步披露已实现：模型按对话分阶段看到工具 —— 初始为 `webpage_open` / `webpage_tabs` / `webpage_execute` / `webpage_tools`；open 或 claim 成功后自动展开 navigate、snapshot、click、fill、press、wait；find、scroll、locate、screenshot、console、network 只能经 `webpage_tools(tools=[...])` 逐项加载，且加载后本对话内不再回缩。加载入口只有必填 `tools`，另外**接受并忽略**可选的 `session_id`（模型会把“操作标签要传 session_id”外推到加载入口，实测整次拒绝 6 次；加载作用于整个对话而非单个标签），其他未知字段仍整次拒绝。定案、真实验收覆盖与未验项见 [工具逐步披露设计](工具逐步披露设计.md)，不以本轮观察优化样本代替全部披露恢复验收。

find、区域读取与增量返回的整体设计见 [网页观察优化方案](网页观察优化方案.md)。下述find续读与局部附观察已实现；动作/等待优先用region_ref，兼容旧名observe_ref，互斥规则见 [网页交互§3.2](网页交互.md#32-动作后观察)。显式局部、原文续读与完整回退已在独立实例取得真实对话证据；整体成本门禁尚未通过，未发布。安装身份、自然路径失败及当前证据见[观察优化续验](records/2026-10-16-网页观察优化续验.md)，不以历史对照代替当前收益。

## 2. 当前规则

### 2.1 页面变化分级

| 信号 | 回执与系统提示的下一步 |
|---|---|
| navigated > 0，文档变化 | 旧 ref 失效；优先使用回执已附的新全页观察，没有附带时先拍完整快照 |
| 仅 within_document、address_drift 或 takeover_window | 不因信号无条件重拍；调用时由运行时检查引用。可信旧引用拒绝随错误附新观察，模型从新 refs 重新选择；大纲与页面不符时主动重拍 |

回执与系统提示使用同一分级规则。仅 query/hash 变化不得同时宣称“ref 未作废”与“所有 ref 已失效”。人工 holder 的拒写规则仍优先执行；交还后必须完成完整观察，内部身份检查不能解除观察门禁。公开 revalidate 已取消，恢复细节统一见 [引用恢复](网页交互.md#31-旧引用与交还恢复)。

不新增遥测 query 键白名单，不放宽 expectSelfNavigation 的一次性抵账。

### 2.2 工具描述与预算

- 全部 webpage 工具的 schema 预算：逐项计算 `JSON.stringify({name, description, parameters}).length` 后求和。当前逐步披露测试守卫为全集≤14000、初始组≤3000、基础组≤9000字符；全集含新增加载入口。历史15工具的13000上限不能直接当当前16工具守卫。实际每步成本按可见集合测量，不混用宿主request/header口径。
- 工具描述保留用途、失效语义、失败码与下一步动作；删去公共重复声明和同义铺陈。
- untrusted 声明保留在系统提示与工具回执中，不逐工具重复拼进 description。
- 关键参数、输出字段和仅存在于 description 的契约锚点分别测试，不能只断言总体积。
- 描述精简后，若真实会话不再正确使用工具，恢复受影响的契约文案，再优化其他冗余。
- 公共 ref 恢复与生成回复操作流程由系统提示统一说明；工具保留最小恢复入口与自身参数条件。有限选项用 enum 声明，区域矩形声明四个必填数值字段；数值范围仍由参数说明和运行时校验共同约束，不使用宿主尚未支持的 minimum/maximum。
- 公共系统提示≤6500字符；当前与全集工具schema求和合计≤20000字符，两项一并守卫，避免仅转移文案。历史披露前合计19000与当前守卫分开记录。导航history、标签action/scope等有限选项也必须声明enum；参数依赖关系仍由运行时验证。
- 每次网页工具执行先按公开 schema 拒绝未知字段、类型/枚举错误和非法 JSON 数值，再执行少量范围、非空标识及跨字段规则；统一回 `BROWSER_INVALID_PARAMS`，不修正、不重跑，也不调用浏览器服务。字段允许集直接取自 schema，不另维护副本。

维护位置：注册入口 `src/tool-browser/index.ts`、公共执行包装 `tool-runtime.ts`、参数规则 `parameter-validation.ts`；契约回归见 `index.test.ts` 和 `parameter-validation.test.ts`。

### 2.3 连续对话等待与区域读取

- 优先等待当前回复独有的完成标记；完成标记同时证明已提交时只等一次，不再分别等输入回显与回复完成。
- 未知完成标记时先做一次必要的区域观察，不用固定 sleep、stable 或反复全页快照轮询生成进度。
- `webpage_wait` 命中或正常超时默认附完整快照并刷新find缓存；region_ref可限定到已知区域。首次、导航、交还后强制完整观察，局部附观察发现新浮层也回退全页。先用附带refs，内容充分就继续。
- 动作后观察：click/press 已知下一步可见正文时用 wait_text，在同一次调用等待并返回新 refs；立即变化且未知标记时用 observe=true。已附观察不重复重拍，默认动作及 fill/scroll 不增加快照。参数、失败语义统一见 [动作后观察](网页交互.md#32-动作后观察)。
- region_box 使用 CSS 像素；高 DPI 下按 Page.getLayoutMetrics 取得的实际比例与 DOMSnapshot 坐标对齐，事实依据见 [CDP 实测](CDP实测事实.md#区域裁剪坐标2026-10-01-补验)。

### 2.3.1 find缓存与原文续读（已实现，未发布）

2026-10-17新增并已实现：只读StaticText大纲行在原maxTextLength预算内预览首尾（约前2/3、后1/3，中间用省略号），便于直接核对尾部标记。短正文不变；超过单项原文缓存上限40000字符时保留前缀预览，不把缓存外尾部拼进预览。控件名称、值、ref身份、去重键和全局大纲预算不变。预览仍折叠空白且省略中间，不能当作完整原文；需要精确内容时继续使用下述full_text和同版本续读。机制测试与独立实例的真实对话边界已验证；自然任务补读减少与整体成本门禁尚未通过，未发布，证据见 [观察优化续验](records/2026-10-16-网页观察优化续验.md)。

find始终只搜索最近成功观察的大纲及缓存正文，不发页面命令；区域观察覆盖搜索范围，不自动合并旧全页。scope指出full、ref:eN、viewport或box范围；observation_id标识本次观察，同一ref epoch中的新区域观察也有新序号。区域零命中不代表全页没有目标。

默认只返回紧凑命中信息与必要的有界正文片段。full_text=true返回原始空白；有完整代码块时优先block，避免同时重复正文行。同一真实正文组只返回一次，不合并两个同文章节。

单项每页最多4000个UTF-16字符，所有命中的正文总预算20000字符，按JSON转义后的正文计，元数据另计；大量换行或控制字符可能提前分页。text_complete与next_text_offset明确完整性和续读位置。续读传read={observation_id,line,offset}，其中line取line_index；保持query并设full_text=true。新观察后旧read返回BROWSER_OBSERVATION_CHANGED，重新find即可，不强制重拍或拼接旧页。内部单项缓存上限40000字符，整份正文缓存合计1000000字符（同组代码只计一次）；source_truncated=true时缓存外尾部不能通过分页恢复，应读取更小来源区域并核对完整性。模型回执用original_text_json表达原文，解码转义并保留全部空白，不能将大纲的扁平空白当原文。

命中数达到limit但不存在下一项时truncated=false；命中截断、原文分页、源缓存截断和大纲截断分别表示。已知目标ref可直接使用，不强制先find再区域观察。

cache_text_truncated=true表示整份正文缓存存在未保留尾部，零命中时也返回并解释；它不等于outline_truncated或匹配数截断。原文无法通过更小区域拆开时，需要其他有界实时读取，不能声称缓存续读能够恢复未缓存内容。

### 2.4 宿主与插件输出预算

维持既有输出预算与宿主 spill/compaction 配置。不得为缩短单条回执而直接把全局 spill 阈值从 50000 降到 16000；该操作会把快照等正常回执一并外置。

新增输出优先使用既有预算、分页与截断机制，不另建一套插件落盘或压缩系统。字符数不能当作精确 token、字节或费用。

## 3. 成本测量与维护

按 [测量口径](上下文膨胀-测量口径.md) 固定版本、模型、任务和配置，分别记录工具定义、系统提示、回执、步数、输入与缓存 token。字符数不能换算为精确 token 或费用；没有受控对照时不宣称因果改善或稳定费用下降。

修改描述同步核对总体预算和契约锚点；新增关键守卫做反向验证，再按真实模型场景确认工具使用与页面效果。费用异常先定位请求前缀、输出、调用步数及宿主压缩链。增量快照、spill 调整与继续压 schema 的启动条件统一见 [遗留问题](遗留问题.md)。

## 4. 回归要求

| 项 | 通过条件 |
|---|---|
| schema 预算 | 当前全集≤14000、初始≤3000、基础≤9000守卫通过；关键契约锚点保留；按可见集合实测请求成本 |
| 不可信内容边界 | description 不重复公共声明；系统提示与回执仍声明不可信内容 |
| 真导航 | 指导完整快照，旧 ref 不被继续使用 |
| 同文档变化 | 不无条件要求全页重拍；可信旧引用错误附新观察，模型使用新 refs 继续，不调用公开 revalidate |
| 搜索与连续对话 | 使用文本等待；不以反复完整快照代替等待结果 |
| 长页面 | 完整观察后使用 find/region_ref；只有截断时才增加快照预算 |
| 输出边界 | 正常快照未因全局 spill 改动被意外外置 |
| 行为兼容 | 网页交互说明的搜索、旧 ref、浮层场景无新增退化 |

历史读数、对照样本及版本结果保留在 [验收记录](验收记录.md)。
