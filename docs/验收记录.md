## 2026-10-18（续）：动作后默认区块观察 + S15 同壳对照（诊断口径，门禁未过）

### 第二轮（对照重建）：同树只差一个旋钮后又抓到两处问题

打包态一跑又抓到两件事：

1. **我自己的归一化实现是坏的**：打包态宿主递进来的 `args` 是**冻结对象**，就地写 `observe` 直接抛 `Cannot assign to read only property 'observe'`（对照组 B-02 的那次工具错误就是它，`errorCodes` 为空正是因为它不是 `BrowserError`）。单元测试里 args 没冻，所以单测全绿。改成 `normalizeToolArguments()` 返回**副本**、`defineTool` 拿副本去校验和执行，并补一条 `Object.freeze` 用例；反向验证：把接线换回原 `args` 后，正是「字符串布尔两条 + 冻结入参一条」三条转红。这条也说明了「单测全绿只证明假设自洽」。
