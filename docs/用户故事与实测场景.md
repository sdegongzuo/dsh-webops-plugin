# 用户故事与实测场景

用途：为网页工具提供可复跑的真实使用场景。每个测试对话只负责一个故事；本文定义期望行为，不表示功能已经通过验收。

## 1. 使用方式

1. 按下表选择故事，新建独立测试对话，发送对应提示词。
2. 准备指定网站或本地夹具；GUI 测试按需错开，不让多个测试同时切换同一窗口。隔离与竞争故事使用协调好的 A/B 对话。
3. 检查真实页面效果、工具参数和模型收到的回执，填写结果记录。
4. 发现问题后按关联方案修复，不在本文复制实现规则。

测试对象是工具：内容答案不评分。模型未调用指定工具、参数填错或偏离流程时单独记录，补一次正确工具调用验证。登录、地区限制、验证码、网络故障记为环境阻塞，不自动归因于工具。

## 2. 单对话故事

### S01 · 网页 AI 连续对话

**故事**：作为研究用户，我想在同一个网页 AI 对话中逐步追问，以便沿用前文信息。

**提示词**：
> 打开 https://www.google.com/ai ，在同一个网页对话里先问“为什么天空是蓝色的”，等回答出现后再追问“那日落为什么偏红”，最后要求它用两句话对比。每轮先确认网页确实收到消息，再等对应回答；报告工具是否顺利完成三轮。

**验收**：三个不同问题实际提交，逐轮等待对应的新回答；不能把上一轮已有文本当成新回答。沿用同一网页对话，不反复新开页面；流式生成不靠持续全页快照轮询。

**环境分支**：入口不可用或没有输入框时报告具体页面状态，停止该站测试；用可访问的流式聊天夹具补验工具。夹具通过不表示 Google 连续对话通过。

### S02 · 搜索、返回与对比

**故事**：作为信息搜集用户，我想打开多个来源并返回继续检索，以便比较资料。

**提示词**：
> 搜索“浏览器无障碍树”，打开一个结果 A 并记下标题和一条信息；返回搜索页，打开另一个结果 B；再次返回并重新打开 A，确认仍是同一来源。后退使用网页导航工具，不用 execute 的 history.back。

**验收**：直链、重定向或新标签的结果与回执一致；返回历史正确；导航后重新快照。点击无效时回执指出遮挡或可执行下一步，不需要先翻 console/network 猜原因。

### S03 · 阅读长文与章节跳转

**故事**：作为文档阅读者，我想从一篇长文中找两个章节，以便只观察需要的部分。

**提示词**：
> 打开 https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide ，查看章节列表，选择两个不同章节，分别找到一个代码示例并说明其位置。首次观察后优先使用 find 和区域快照；只有明确截断时才扩大快照预算。

**验收**：章节跳转真实生效，示例可在当前页面定位；find 搜索的是正确页面缓存。记录完整与区域快照次数、截断情况和回执体积，不把模型摘要质量算作工具结果。

### S04 · 登录浮层阻挡页面

**故事**：作为阅读者，我想知道链接为什么点不开，并在处理浮层后继续阅读。

**提示词**：
> 打开指定的带登录浮层页面或遮挡夹具，用小快照观察，再尝试点击浮层下方的指定链接。报告遮挡来源；按我指定的关闭控件关闭浮层，再点同一链接。不要自动登录或猜测关闭按钮。

**准备**：无 dialog/aria-label 的 fixed wrapper、无文本 backdrop、中央表单；另选一个真实浮层页面复验。

**验收**：小快照首屏提示浮层；被盖目标连续三次均能报告遮挡，名字可读或明确未知；关闭后一次点击生效。截断大纲上 find 零命中时给出截断解释。真实页面未出现浮层不算该场景通过。

### S05 · 带联想的表单

**故事**：作为表单用户，我希望填写内容不会在提交时被联想选项替换。

**提示词**：
> 在本地搜索表单夹具中输入“浏览器工具测试”，等待联想出现，然后对同一输入框按 Enter 提交。检查页面接收到的查询与原输入完全相同。再填写一个普通字段，确认旧字段没有被误改。

**验收**：页面侧收到准确输入值；提交发生一次；联想不改写查询；其他字段不变。使用夹具的页面计数和接收值验收，不以 fill 回执成功代替。

### S10 · 有期限的页面调试

**故事**：作为开发者，我想读取页面状态和诊断记录，并在表达式挂起时快速得到明确失败。

**提示词**：
> 在调试夹具读取一个简单状态值，再分别查看同一时间段的 console 和 network。随后用 execute 测试函数返回值、深层对象和永不完成的 Promise；Promise 设置 timeout_ms=2000。逐项说明工具返回的边界与恢复建议，不修改业务数据。

**验收**：普通值正确；诊断数据可对应时间范围；函数与超深对象不静默返回空对象；挂起调用约三秒内结束等待，回执说明结果未确认与副作用边界。超时不等于表达式已经取消。

## 3. 人工参与与多对话故事

### S06 · 人工中途接管

**故事**：作为与 agent 共用页面的人，我想随时接管并稍后交还，以便修改它正在处理的内容。

**执行**：对话 A 打开表单夹具并观察；测试人员按“接管”，改变页面或导航；要求 A 尝试写入；再按“交还”，让 A 重新观察后继续。

**验收**：人工接管期间 A 明确拒写；不会自动交还。交还后旧 ref 不复活，重新观察后可以继续；另一对话不能因人工接管而领取 A 的标签。

### S07 · 两个对话并行使用浏览器

**故事**：作为并行处理任务的用户，我希望每个对话管理自己的网页，避免相互读取或操作。

**A 提示词**：
> 打开文档页面并保持标签。列出本对话标签，记录你的标签 id；继续在自己的页面找一个章节。

**B 提示词**：
> 打开搜索页面并列出本对话标签。随后按测试人员给出的 A 标签 id，分别尝试 snapshot、navigate、activate 和 close，记录拒绝结果。不要换用其他工具绕过拒绝。

**验收**：A/B 默认清单不互见占用标签；外来 id 全部拒绝且 A 页面不变。代码回归还须覆盖全部读写工具，不能用四个 GUI 抽样代替全量门禁。页面弹窗继承创建者归属。

### S08 · 超时释放与恢复

**故事**：作为偶尔离开任务的用户，我希望闲置标签自动释放，同时保留页面以便继续。

**执行**：测试配置租期临时设为 60 秒。A 打开夹具后不再调用目标工具，等待真实到期；B 查看空闲清单并领取。A 再尝试使用旧 id。另跑一条跨过截止时间的执行中调用；验后恢复默认租期。

**验收**：空闲到期只释放、不关页面；B 领取后重拍快照才能操作；A 明确失去权限。执行中的调用不被中途释放。B/C 同时领取时只有一个成功；用 release 或改系统时间不能代替超时测试。

### S09 · 移交网页任务

**故事**：作为切换任务的用户，我想把当前页面明确交给另一对话，以便保留页面状态继续处理。

**执行**：A 发起 handoff，测试人员把一次性码带到 B；B 用码领取后重新观察。A 尝试继续操作；另测错码、重复码与过期码。

**验收**：B 领取前无人可直接读写待移交页面；领取后只有 B 有权限。错误、过期和重放均拒绝；原页面保留，旧 ref 失效。执行中不可移交；普通清单不包含移交码。

## 4. 结果记录

每个故事填写一条记录，失败时附最小复现，不追加整段对话过程。

| 字段 | 内容 |
|---|---|
| 故事 / 对话 | S 编号；A/B 角色与对话标识 |
| 环境 | 插件版本、宿主版本、provider、站点或夹具、必要配置 |
| 结果 | 通过 / 工具失败 / 环境阻塞 / 未执行完 |
| 页面证据 | 导航、输入接收值、滚动位置或页面计数；必要截图 |
| 工具证据 | 参数、回执、错误码、耗时、关键调用顺序 |
| 模型偏差 | 参数错误或偏离流程；正确调用复验结果 |
| 问题与去向 | 具体缺口、复现步骤、关联实施方案 |

需要成本比较时使用 [测量口径](上下文膨胀-测量口径.md)。通过标准以工具和页面证据为准；不能只写“模型说完成了”。
