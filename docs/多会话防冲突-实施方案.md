## 1. 实施目标与范围

每个受控浏览器标签同时最多由一个宿主对话占用。所有页面读写与标签管理操作均检查调用方；空闲超时自动释放占用，保留页面。

本次实现：对话身份校验、标签占用、清单过滤、释放与领取、超时回收、弹窗归属、一次性移交。

已有写前门、页面变化通知、`reboundRefs` 与人工接管继续生效。快照压缩与点击改进分别按 [上下文膨胀方案](上下文膨胀-实施方案.md)、[网页交互方案](webpage交互改进-实施方案.md) 执行。

## 2. 身份与状态

### 2.1 调用方身份

- 从每次工具执行上下文 `exec.agent.id` 获取宿主对话身份。
- 模型参数不得包含 ownerId；浏览器 `session_id` 只表示标签，不表示对话。
- 缺少身份时拒绝模型工具调用。直调 provider 的测试入口不得成为生产绕过路径。
- 内部占用主键使用 `(providerId, targetId)`，模型仍使用当前 provider 的标签 id。

### 2.2 占用状态

| 状态 | 可见范围 | 操作权限 | 离开条件 |
|---|---|---|---|
| `occupied` | 仅 owner 的默认清单 | 仅 owner | 显式释放、空闲超时、移交、标签关闭 |
| `free` | 空闲清单，只显示标签 id | 先领取，再读写 | 原子领取成功 |
| `handoff` | 不进入普通清单 | 持有效移交码领取后才可读写 | 领取成功；码过期后转为空闲 |

占用记录包含 ownerId、generation、空闲截止时间、activeCalls。移交状态保存码的哈希与截止时间。

### 2.3 与人工接管的关系

对话占用与 `holder: agent/human` 分别管理。

- 人工接管不释放对话占用，其他对话仍不能操作。
- `open` 优先领取相同规范化完整 URL 的空闲受控标签并复用页面，不重新导航；占用中、移交中、未登记的人工标签及不同 URL 不复用。领取后旧 ref 作废，复用时切到前台并获取新快照。
- 空闲释放不改变 holder，不替人按“交还”。
- 人工接管时保留 `BROWSER_HUMAN_HOLDING` 拒写规则；交还后不恢复旧 ref。
- 保留现有唯键盘输入限制与标签条接管按钮，不新增 holder 空闲计时器。

## 3. 超时与生命周期

| 配置 | 默认值 | 校验 |
|---|---|---|
| `tabLeaseIdleMs` | `1800000`（30 分钟） | 正整数 |
| `tabHandoffTtlMs` | `300000`（5 分钟） | 正整数 |

配置放在 browser 插件中，错误提示明确指出字段与允许值；不以 `0` 关闭门禁。

### 3.1 续期和回收

1. 获授权的目标标签工具调用开始时增加 activeCalls。
2. 调用完成后在 `finally` 中减少；弹窗家族中最后一个执行中调用结束时，统一重置同 owner 的所有占用成员的空闲截止时间。整族回收与整族续期使用一致粒度，父标签的旧期限不得释放刚完成调用的子标签。网站或 CDP 失败也续期。
3. 越权、错参、无目标的清单查询和重复领取均不续期。
4. activeCalls 非零时不得超时释放。取消后须确认底层调用真正结束，不能提前标成空闲。
5. 定时器使用单调时钟并核对 generation；每次查询和操作也执行惰性过期检查。
6. 到期只释放占用，保留页面。原 owner 必须重新领取；别人已领取时明确拒绝，不等待、不抢占。

普通模型单轮结束、窗口失焦、对话归档不直接释放占用。30 分钟为首版默认值，后续按真实工具调用间隔调整。

### 3.2 ref、缓存与重启

- 释放、移交、关闭时清理对应 snapshot/find 缓存，作废 ref 纪元。
- 空闲标签被领取或移交给新 owner 后必须重新拍完整快照。
- 同一 owner 重复领取自己仍占用的标签幂等成功，不推进纪元。
- 占用表、移交码和定时器只保存在内存；插件卸载时注销订阅并清理运行状态。
- 重启不从历史回执恢复权限，不按 URL、标题或旧标签号收编外部浏览器残留页面。
- 切换 provider 时不迁移旧占用记录。

## 4. 工具接口

扩展 `webpage_tabs`；其余网页工具不增加模型身份参数。

| 调用 | 行为 |
|---|---|
| `list` | 仅列当前对话占用标签，返回标题、URL、前台状态和剩余租期 |
| `list, scope=available` | 仅列本运行实例受控且空闲的标签 id，不返回标题、URL、其他 owner 或用户原有标签 |
| `claim, session_id` | 原子领取空闲标签；回执要求先拍快照 |
| `release, session_id` | owner 释放，不关闭页面；回执只列剩余自有标签 |
| `handoff, session_id` | owner 发起移交，立即失去操作权；返回一次性移交码 |
| `claim, session_id, handoff_code` | 持有效码原子领取，码只消费一次 |
| `activate/close, session_id` | 仅 owner 可执行；外来或过期 id 必须拒绝 |

所有带 `session_id` 的网页工具均受门禁保护，包括 snapshot、find、console、network、screenshot，以及 navigate、click、fill、press、scroll、execute、revalidate、locate、wait。

先验证参数，再检查占用，随后执行现有页面保护和 provider 调用。拒绝越权时不派发页面命令，不泄露标题、URL或其他对话状态。`opened_tabs` 只返回当前 owner 的新标签。

### 4.1 错误与恢复路径

| 错误码 | 条件 | 回执指导 |
|---|---|---|
| `BROWSER_CALLER_REQUIRED` | 缺少宿主身份 | 修复身份传递，不能用模型参数补身份 |
| `BROWSER_TAB_NOT_HELD` | 外来、过期或未持有标签 | 先领取；成功后重新拍快照 |
| `BROWSER_TAB_OCCUPIED` | 领取竞争失败 | 使用其他空闲标签或等待释放，不能抢占 |
| `BROWSER_TAB_BUSY` | 执行中释放、移交或关闭 | 等执行中调用结束后重试 |
| `BROWSER_HANDOFF_INVALID` | 移交码错误、过期或已消费 | 获取新的移交码，不能重放旧码 |

在 `src/browser/types.ts` 声明错误码，并测试完整恢复文案。无效 scope、遗漏参数或不适用的 handoff_code 不改变占用记录。

### 4.2 移交码

使用至少 128 位密码学随机数，表中仅保存哈希；校验与消费放在同一次原子迁移中。

用户将工具回执里的码带到目标对话。任何持有效码的对话都可领取，不依赖目标对话 id。码不进入普通清单、额外调试日志、指标或标题；宿主对话历史会保存工具回执与领取参数，因此短有效期和一次性消费必须生效。

码到期后标签转为空闲，页面保留。只需开放给后来者时使用 release。

## 5. 实现位置与并发规则

| 位置 | 工作 |
|---|---|
| `src/tool-browser/index.ts` | 提取 exec.agent.id；所有网页工具使用统一受控入口；扩展 tabs 参数、输出与错误文案 |
| `src/browser/index.ts`、`src/browser/types.ts` | BrowserRuntime 持有占用服务；统一裁决工具调用和状态迁移，定义配置与错误 |
| `src/browser-cdp/provider.ts`、`src/browser-electron/provider.ts` | 创建、弹窗、关闭事件接入占用服务；底层全量清单仅供内部过滤 |
| `src/browser-cdp/refs.ts` | 提供归属变化时的 ref 作废路径 |
| `src/browser-electron` | 保留人工接管语义；首版不增加绕过占用服务的移交控件 |

### 5.1 原子性

- 每个标签独立裁决，不锁整个浏览器；不同标签可并行。
- 占用校验与实际调用进入同一个受控入口，禁止工具层检查后直接裸调 provider。
- 调用排队时记录 generation，真正派发前再次核对；旧 owner 的排队调用不得在移交后执行。
- release、handoff、close 遇到 activeCalls 非零直接报忙。
- claim 竞争只能一个成功；旧定时器不得回收新 generation。
- open 在返回标签 id 前完成 owner 登记；登记失败时关闭刚创建的受控标签并报错。

### 5.2 弹窗

通过受控父标签识别弹窗归属，登记后才加入回执：

- 父标签被占用：子标签继承 owner，不先暴露为空闲。
- 父标签空闲或移交待领：子标签继承该状态，不给旧 owner 续期；移交子标签与父标签在同一次领取中迁移。
- 人工新建或没有受控父标签的页面：不猜 owner，不进入可领取清单。
- 标签或窗口实际关闭：注销占用、定时器与缓存。

## 7. 验收清单

| 场景 | 必须满足 |
|---|---|
| A 开 t1，B 开 t2，分别 list/available | 各自只见自有占用标签，空闲清单不见二者 |
| B 用 t1 调全部读写与管理工具 | 门禁拒绝；A 页面、ref、标签不变，无页面命令派发 |
| A 页面产生弹窗 | 仅 A 可见和操作，B 不能读写或关闭 |
| A 释放，B/C 同时领取 | 恰一方成功；旧 ref 失效，完整快照后可操作 |
| A 移交，B 用正确码，C 用错码 | 正确码仅成功一次；错码、重复码、过期码拒绝 |
| 父标签在移交期间产生弹窗 | 父子状态一致；领取时一并迁移，其他对话不可见 |
| 活跃调用跨过截止时间 | 不中断、不释放；实际调用结束后续期 |
| 空闲超时后旧 owner 再调用 | 页面保留、占用释放；旧 owner 须重新领取和拍快照 |
| 旧定时器在新租期内触发 | 不释放新 owner 或新租期 |
| 人工接管、交还与租期交叉 | 他人不能越权；人工接管仍拒写；交还不复活旧 ref |
| 用户原有标签与运行实例重启 | 不误收编，不恢复历史权限 |

验证顺序：

1. 注入时钟覆盖租期与移交到期边界，覆盖异常、取消和领取竞争。
2. 反向验证：临时移除门禁，外来 snapshot/close 用例必须失败；恢复后通过。
3. 运行 `pnpm typecheck`、`pnpm test`。
4. 更新固定测试目录并重启，以两个真实宿主对话验证清单、越权、释放、领取、弹窗、移交和人工接管。
5. 打包态临时将租期设为 60 秒，等待真实超时；完成后恢复 30 分钟并核对配置。不用 release 或修改系统时间替代超时验收。
6. 将本文件状态从“待实施”改为“已实现”；仅在打包态验收完成后标记“已验收”。记录提交、测试命令结果、产物版本和未完成项。
