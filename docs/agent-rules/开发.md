# 开发规则

修改源码、脚本、本机配置前阅读。架构接线见 [架构与实现](../架构与实现.md)；命令见 [开发指南](../开发指南.md)。

## 1. 编辑与回执

- 同一文件串行编辑；每次编辑后核对关键符号与预期 diff，避免并行 Edit 覆盖。
- 字符串字面量逐处修改，不用正则批量换引号；包含插值的回执必须断言完整输出文本。
- AX 树夹具按真实浏览器形状构造；新 CDP 命令先读 [CDP 实测事实](../CDP实测事实.md)。
- 截断、丢弃、折叠、去重、区域外计数分别报告，不混用口径。

## 2. 本机路径

脚本通过 `scripts/local-env.mjs` 读取本机目录，值写在不入库的 `.env.local`；入库模板为 `.env.local.example`。本机绝对路径不得写进脚本。终端用户的占位路径与文档示例不受此限制。

修改配置模块前读其文件头，维持三条语义：

1. 环境变量优先，文件仅补默认值。
2. 文件不存在可接受，CI 由 workflow 显式传值。
3. 缺必需键时报键名、配置位置与示例，不静默回落到某台机器的目录。

新增键同步 `KNOWN_KEYS`、`.env.local.example` 与说明；键名清单以源码和模板为准，AGENTS.md 保留任务入口，不重复列键。

查来源使用 `pnpm portable:env`。构建大件与固定测试目录设在工作区外，避免 IDE 持有 asar 句柄。

## 3. 脚本与运行时

- `scripts/*.mjs` 能独立执行；参数缺失给可读用法，失败 exit=1。
- 打包态 process.execPath 是主 exe，不能直接假设它是 Node。
- 自定义宿主变量使用合适的 DSH_* 名称；DSH_DESKTOP_ 前缀会被宿主过滤。
- 运行时目录走 `scripts/desktop-runtime.mjs`；按 resources/dsh 判布局，不恢复已退役的 profileResolution 分支。
- 排查开发态与打包态环境差异时核对 main.ts 顶层默认值；需要双击 exe 生效的修复落在顶层判空兜底，不能只改启动脚本。
- 临时 ESM 脚本放项目根并使用相对导入，避免跨盘绝对导入解析问题。

## 4. 文档与规则维护

- 每条执行规则只有一个权威位置；入口写触发条件与链接，细节放被链接的文档。
- 主方案只保留当前规则、实施步骤、验收要求；必要测量方法或机制依据放二级文档。
- 历史结果标明日期、样本和限制；功能状态按源码与本轮证据更新，不把旧数字写成当前保证。
- 新增或调整按需文档时同步 AGENTS.md 路由，并核对入站引用与链接目标。
