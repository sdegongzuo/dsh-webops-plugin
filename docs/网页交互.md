# 网页交互

本说明定义页面动作、等待、引用恢复、截图与 execute 的当前契约。工具参数以公开 schema 和运行时校验为准；具体 CDP 事实见 [CDP 实测事实](CDP实测事实.md)，成本规则见 [快照与上下文](快照与上下文.md)。

2026-10-16源码候选将动作/等待的区域参数统一为region_ref，兼容旧名observe_ref。局部与完整回退机制已有实测，新命名尚待真实对话验收，稳定采用及整体成本收益仍待优化，尚未作为发布功能交付；安装身份与结果见验收记录。

## 1. 操作原则

调用先校验参数、对话权限、人工控制和引用状态。回执区分输入已派发、页面结果已确认、结果未知。模型按当前页面重新决定下一步；工具不会自动提交、关闭浮层、补按 Enter/Escape 或重放失败动作。

## 2. 工具行为

| 功能 | 保持的行为 |
|---|---|
| 旧 ref | 节点消失或文档变化使用 BROWSER_STALE_REF，提供恢复路径，不透出裸节点错误 |
| click | elementFromPoint 校验落点；命中遮挡**在派发前拒绝**（BROWSER_TARGET_OCCLUDED，本次输入未派发）；无跳转时返回目标与下一步，不自动补 Enter/Escape |
| locate | centered 是测得的「真居中」事实（元素中心对齐视口中心，±16px 容差；超视口的轴按完全覆盖判），「看得见」不算居中；视口测不到或为零时恒 false；smooth 动画重测到居中为止（有界 ≤600ms） |
| 零视口窗口 | innerWidth/innerHeight=0（最小化 / 隐藏）时 click / scroll / locate 一律拒绝（BROWSER_WINDOW_NOT_VISIBLE），不派发任何事件、不代恢复（host.cjs 退化读数守卫是唯一权威） |
| fill | 保留现有 setter 路径；带联想的搜索框指导 fill 后对同一 ref 按 Enter，不自动点提交按钮 |
| scroll | 后台标签先激活或明确拒绝；wheel 使用 2 秒专用等待，允许返回“已投递未确认”，总体 3 秒内返回 |
| 历史导航 | url 与 history 恰好一个；back/forward 使用 CDP 历史接口，reload 使用 Page.reload；尽头明确报失败 |
| 导航后 | 作废 ref 与 find 缓存，下一步 snapshot，不直接 find |
| snapshot | 浮层提示在大纲顶部；无 dialog/aria-label 的浮层也尝试读取可读名字 |
| find | 发布版只搜索缓存大纲；源码候选同时匹配缓存正文并标范围、版本和完整性，详见 [快照与上下文](快照与上下文.md)。零命中不自动补快照 |
| wait | 恰好选择一种条件；`time_ms` 为固定延时且不能与 `timeout_ms` 同用，文本/ref/stable 共用 1–30000ms `timeout_ms`（默认 10000ms）；命中或正常超时（`satisfied=false`）后默认返回完整快照，新 refs 可直接用且 find 缓存已刷新。候选region_ref范围与回退见§3.2 |
| execute | 唯一模型参数为 session_id、code、可选 timeout_ms；code 是一次性 async 函数体。{}、[]、null 合法；undefined 明确标 has_value=false；DOM 与非 JSON 结果明确拒绝 |

浮层名字优先 aria-label/alt，再读自身或有文本祖先；向上最多 5 层且不读 body，片段最多 60 字。不得把整页正文当成浮层名。

execute 的 timeout_ms 范围为 1–30000，默认 5000 毫秒；provider 仍取请求预算与自身 commandTimeoutMs 的较小值。超时回执说明结果未确认，页面函数可能继续，副作用不会回滚。代码不自动补 return、不改写参数、不重跑。

每次调用把 code 放入新的 async 函数体，因此局部 const/let 不跨调用；window/globalThis 赋值、DOM 修改和网络请求仍可持续存在。返回数据限普通 JSON 值；页面内检查拒绝 DOM 节点、访问器、函数、循环引用、非普通对象和超预算结构，不调用 getter 或 toJSON。大文本会裁剪并标 truncated；大结构报错并要求只 return 所需字段。受控组件操作使用 click/fill/press，不把直接改 DOM 当成可靠输入路径。

## 3. 引用、观察与结果

### 3.1 旧引用与交还恢复

模型侧不提供 webpage_revalidate。节点失效、文档变化或交还观察门禁拒绝原动作；只有可信确认输入尚未派发的引用错误才可在同一失败回执附一次完整观察。

| 状态 | 处理 |
|---|---|
| 当前 ref 有效 | 保持正常执行，不增加恢复快照或模型工具调用 |
| 可信错误确认 ref 已失效，且输入事件尚未派发 | 停止本次动作；在原租约和同标签操作序列中取得一次完整快照，随错误返回新 refs，让模型重新选择目标 |
| 导航或刷新导致旧引用失效 | 同样拒绝旧动作并返回当前文档的观察，不能按同名控件自动换目标 |
| 人工持有、标签不属于当前对话 | 保留拒绝，不自动恢复或观察他人的标签 |
| 交还后尚未完成完整观察 | 在 provider 的输入派发入口硬性拒写；可以附带一次交还后完整观察，但本次失败动作不能借此继续执行 |
| 输入已派发或状态未知、取消、超时、连接丢失 | 不重跑、不附加恢复动作；保留实际错误与结果未知边界 |

恢复观察保持原 owner、session 和租约代次，在同标签队列内执行；取消候补不能越过仍运行的前任。使用原信号与剩余工具预算，子预算最多 2 秒。观察失败保留原错误并说明未取得新观察；回执仍为 isError=true。完整观察刷新 find 缓存并提供 epoch、截断状态与新引用，原动作不会借补拍继续。

交还后仅成功的完整观察可清除 needsReobserve，区域观察和内部身份诊断不能解除该门禁。页面可能随后变化，新引用仍需接受正常有效性检查。

### 3.2 动作后观察

`webpage_click` 与 `webpage_press` 默认只返回动作回执，不增加观察。需要读取动作结果时传observe=true，在同一租约与标签队列内附快照；已知本轮独有正文标记时传wait_text，等待后观察。timeout_ms是1–30000ms等待期限（默认10000）：配wait_text时是完成等待期限；仅配observe=true时，动作后先等页面安静（until=stable）至多该期限再观察。wait_text总会附观察，此时observe字段被忽略，不再因observe=false拒绝；三种等待（文本/ref/stable）之外的裸timeout_ms仍在派发前拒绝。文本命中与正常超时都会观察，超时satisfied=false；stable不证明业务完成。

源码候选使用region_ref指定附观察区域，填写已观察到的结果区标题anchor或容器ref，与snapshot.region_ref同义，不是点击目标ref。click/press必须同时启用observe=true或wait_text，wait可直接指定且不接受observe参数。旧名observe_ref继续兼容，但与region_ref互斥，即使值相同也拒绝；空白、非法类型及缺少观察条件都在派发前拒绝。布尔observe必须用true/false，不接受字符串。

动作内stable等待保留provider返回的`signals`（readyState、DOM与network），与独立wait使用同一输出契约。回执明确页面安静不证明业务完成，不要求为再次确认安静重复stable等待；检查本轮结果，缺少尾部时读取已知结果区域。文本等待不伪造安静信号，正常超时仍保留实际信号；这项回执补正不自动选择区域，也不保证模型不会补读。

首次、真导航后和交还后仍强制全页；局部附观察检查到新浮层时回退全页。实际scope来自provider，find缓存与回执使用同一实际范围；不以请求参数冒充已经取得的区域观察。区域外已有引用仍按原规则校验，观察失败不重放动作。新旧参数名都映射到原有BrowserRuntime观察路径，不增加自动动作或新的缓存。

点击或按键成功派发后，若等待或快照失败，回执保留原动作事实并标 `action_dispatched=true`、`observation_error`，提示不要重发动作；等待失败不再追加快照。原动作未成功返回时继续沿用原错误和可信的派发边界，不进入这条后处理路径。所有阶段共用原 `exec.signal`，取消时不保证后处理回执仍能到达调用方。

### 3.3 可操作控件与只读锚点

click/fill/press 使用 `[ref=eN]` 控件，`[anchor=eN]` 标题只供定位和读取。恢复大纲已包含所需控件时直接使用新引用；内容缺失或截断时才继续 snapshot/find。

### 3.4 截图

元素截图检查节点连接和文档身份，以视口坐标测量并处理滚动偏移。Electron 后台截图使用有界出帧、页面捕获与 nativeImage 裁剪；临时可见性与输入共用窗口调度，结束时按最新选择恢复视图。截图失败或超时如实返回，不能以工具成功推定裁剪或内容正确。

## 4. 错误处理

非法字段、类型、枚举及跨字段条件返回 BROWSER_INVALID_PARAMS，参数不自动修正。遮挡在派发前拒绝；零视口明确拒绝而不自动恢复窗口。输入已派发后观察失败保留派发事实；超时和断线不能推断无副作用。标签不属于当前对话时不会读取他人页面作为恢复。

窗口人工前台、排队超时、撤销与 blocked 的回执和处理见 [并发网页操作](并发网页操作.md#截止时间与回执)。

## 5. 回归场景

| 场景 | 操作 | 通过条件 |
|---|---|---|
| A：连续输入 | Google AI 模式或可用流式页面，两轮 fill + Enter + 文本等待 | 两次输入与结果均实际出现，不在 busy 时加长 stable 空等 |
| B：搜索联想 | fill 查询后同 ref Enter | 提交查询与输入一致；导航后先 snapshot |
| C：打开、返回、再打开 | 直链、重定向、target=_blank，随后 navigate history=back | 导航或 opened_tabs 与页面一致；返回走专用工具；未导航时回执足以决定下一步 |
| D：旧 ref | 导航后不重拍，使用旧 ref | BROWSER_STALE_REF，文本有恢复指引，无裸 No node with given id found |
| E：浮层 | 全屏浮层，小快照，点击下方目标，关闭后再点，截断 find | 首屏有 OVERLAY；连续 3 次遮挡不丢；关闭后真实点击生效；零命中解释截断 |
| F：滚动 | 前台长文、另一站点、后台标签各滚一次 | 每次 ≤3 秒；激活或拒绝明确；记录页面实际滚动位置 |
| G：execute 边界 | return 的普通对象、{}、[]、null、undefined、DOM、循环与深对象；连续两次声明同名局部变量 | 空值类型明确可分；undefined 为 has_value=false；不可序列化有边界错误；局部变量互不冲突 |
| H：execute 超时 | 永不完成的 Promise，timeout_ms=2000 | 约 2 秒结束主等待；错误码分类明确，说明结果未知、代码可能继续和副作用边界；验证无自动重跑及超时参数范围 |
| I：空点与探测失败 | 空点夹具；注入 hitTest 异常 | 分别报告空点、无法探测，不能都呈现为无遮挡 |

回归使用可控页面记录真实副作用，结合原始工具回执和原生 GUI；不可访问的站点记录环境阻塞。版本结果统一见 [验收记录](验收记录.md)，当前需补的故障边界见 [遗留问题](遗留问题.md)。
