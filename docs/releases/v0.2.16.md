# v0.2.16 · execute 函数体接口与独立插件发布

`webpage_execute` 改为 async 函数体接口，模型只提供 session_id、code 和可选 timeout_ms。CDP 参数由插件内部处理，支持多语句、await 和显式 return，并准确区分参数、代码、结果序列化和超时失败。

## 接口变更

```json
{
  "session_id": "t1",
  "code": "const title = document.title; return { title };",
  "timeout_ms": 5000
}
```

- 旧 method、params、expression 形状不再接受；未知字段在派发前拒绝。
- timeout_ms 默认 5000 毫秒，可指定 1–30000 的整数，且不放大 provider 自身预算。
- {}、[]、null 正常返回；无 return 明确表示 has_value=false。DOM、函数、访问器、循环及超预算结构明确拒绝。
- 代码只执行一次。超时仅停止等待，页面代码可能继续，副作用不回滚；先检查页面状态再决定是否重试。

## 其他改动

- 网页操作记录支持向上展开、失败筛选及按需显示页面和失败详情，减少默认入口占用。
- 按职责拆分网页工具及 CDP 实现，保留身份、租约、人工接管、导航纪元与缓存门禁。
- 插件与 DSH 桌面整包分开发版；本次下载为独立插件 ZIP。
- 构建流程对齐 DSH alpha.2 的运行时路径和上游固定提交，并检测 electron-builder 原生 rename 重试能力。

## 安装与更新

下载 `dsh-webops-plugin-v0.2.16.zip`，完全退出 DSH 后，将 ZIP 内容合并覆盖到实际加载的插件目录，再重新启动。便携版默认目标为 `home/profiles/desktop/node_modules/dsh-webops-plugin/`，不能解压到便携版根目录。保留用户 home、profile 登记与旧 chunk。首次安装见 [安装说明](../portable-install.md)。

## 验证与限制

类型检查通过，全量 752 项测试通过且零跳过；Chrome 与 Electron 补充边界各 31 项通过。新旧各 20 个 U2 Flash 真实新对话中，参数成功率均为 20/20，首次所需数据完整从 15/20 到 19/20；总 execute 次数均为 23。候选最终数据完成 19/20，有一轮把相对 href 当成完整地址，故不宣称整体任务准确率提升。详情见 [验收记录](../验收记录.md)。

模型仍负责页面代码的语义正确性；本版本不自动改写代码，也不承诺所有异常均可提供源码行号。异步导航及仅 query/hash 漂移沿用现有边界，实际导航优先使用 webpage_navigate。
